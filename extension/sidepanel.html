When “Follow my tab” is on, the AI reads and works in the tab you're looking at. Chrome shows a bar while it's attached; Cancel there pauses it. Buying, sending or deleting always asks you first.

Connect to Albatross

  1. Open Albatross (the button below, or your usual tab).
  2. Settings → Tools → Work on your PC → Browser: My Chrome → Make a code.
  3. The code is copied for you and appears here by itself. If not, paste or type the 6 digits.

Albatross isn't running

The Albatross host on this PC is off. Start it, then this panel connects by itself.

My tools

Make your own tools for the AI. It sees each one as my_name and uses it when your question fits. A tool either runs a bit of JavaScript on the page you're on, or hands the AI a ready-made text to follow.
Tools from a file can run code on the pages you visit with the AI. Read them before you add them, and only add tools from people you trust.
