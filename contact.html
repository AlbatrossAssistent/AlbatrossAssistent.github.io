Contact

We read everything and answer in English or German.

Albatross is open source and developed in public. The fastest way to reach us is an issue on GitHub: you get an answer there, and others with the same question find it too.

Questions and help

Something not working, or not sure how to do something? Open an issue on GitHub and describe what you tried. A screenshot of the opening screen (it shows which connection fails) helps a lot. Many answers are already in the guides.

Bug reports and ideas

Report bugs and suggest features in the issue tracker. Please include your Albatross version (Settings → bottom of the sidebar) and whether you use the website, the Windows app or the Chrome extension.

Privacy requests

Albatross stores almost nothing about you; most data can be deleted directly by you (see the privacy policy). For anything else, open an issue. Never post your PC code, passwords or personal data in an issue.

Security reports

Found a vulnerability? Please don't post the details publicly. Use GitHub's private vulnerability report so we can fix it first.

Source code

Everything Albatross does is public: github.com/AlbatrossAssistent.
